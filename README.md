# Smart Home Automation

Smart Home Automation is an IoT-based project that integrates a Flutter mobile application with hardware to provide convenient home monitoring and control. The system allows users to monitor the status of connected home devices and control selected appliances and security features using a smartphone.

The application supports both manual and voice-based commands, allowing users to interact with supported devices through the mobile interface or spoken instructions.

## Features

- **Real-Time Home Monitoring** – View the current status of connected home devices through the mobile application.
- **Voice Command Control** – Use spoken commands to control supported smart home devices.
- **Smart Light Control** – Turn connected lights on or off using the mobile app or voice commands.
- **Door Lock Control** – Lock or unlock the connected door through the mobile application and supported voice commands.
- **IoT Hardware Integration** – Connect the Flutter application to hardware that performs the requested device operations.
- **Mobile Device Control** – Manage supported home devices conveniently using a smartphone.

## Technologies Used

- **Flutter** – Mobile application development framework
- **Dart** – Programming language for the mobile application
- **Arduino IDE** – Used for hardware programming
- **IoT Hardware Components** – Used to monitor and control connected home devices

## Project Overview

This project demonstrates the integration of mobile application development, voice commands, and IoT hardware to create a smart home automation system. It provides users with a convenient way to monitor their home and control supported devices through manual interactions or spoken instructions.
